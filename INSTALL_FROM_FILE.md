# Установка Auto Translate из файла

Эта инструкция предназначена для Android. Для установки нужен **Revenge Next** — именно в нём есть штатная кнопка **Install from file**.

## Что понадобится

- Android-смартфон;
- APK Revenge Manager;
- файл плагина `com.gleb.autotranslate.zip`;
- интернет-соединение.

> Revenge является сторонней модификацией Discord и не связана с Discord Inc. Использование модифицированного клиента может нарушать правила Discord. Установка выполняется на ваш риск.

## Быстрая установка, если Revenge Next уже установлен

Проверьте наличие пункта:

```text
Настройки Discord → Revenge → Plugins
```

Если пункт **Plugins** есть, переходите сразу к разделу [Установка ZIP](#установка-zip-плагина).

## 1. Установка Revenge через Manager

1. Откройте официальную страницу:

   <https://github.com/revenge-mod/revenge-manager/releases/latest>

2. В разделе **Assets** скачайте APK. На момент написания актуален:

   <https://github.com/revenge-mod/revenge-manager/releases/download/v1.3.0/revenge-manager-1.3.0.apk>

3. Если Android попросит разрешение, разрешите браузеру или файловому менеджеру установку приложений из неизвестного источника.
4. Установите и откройте Revenge Manager.
5. Запустите установку Revenge/Discord и следуйте шагам Manager.
6. Если Android сообщает о конфликте подписи, сохраните данные для входа, удалите установленный официальный Discord и повторите установку через Manager.
7. Откройте установленный Discord и войдите в аккаунт.

Manager может первоначально установить Revenge Classic. Если в настройках уже присутствует **Revenge → Plugins**, следующий раздел можно пропустить.

## 2. Простой переход на Revenge Next

Официальный Revenge Next распространяется как `revenge.bundle`, а не как отдельный APK. Автор плагина размещает production-сборку из официального исходного кода по постоянному HTTPS-адресу, поэтому компьютер и локальный сервер пользователю не нужны.

1. В Discord откройте **Настройки → Revenge**.
2. Включите **Developer Settings**.
3. Вернитесь назад и откройте появившийся раздел **Developer**.
4. Найдите **Load from custom URL** и включите его.
5. Введите постоянный адрес bundle:

   ```text
   https://repo.gpodvorotov.ru/revenge.bundle
   ```

6. Полностью закройте Discord и откройте его снова.
7. Проверьте, что появился пункт:

   ```text
   Настройки → Revenge → Plugins
   ```

Не отключайте **Load from custom URL**: Discord использует этот адрес при следующих запусках. Bundle обновляется владельцем сервера из официального проекта Revenge Next.

Официальная инструкция перехода:

<https://github.com/revenge-mod/revenge-bundle-next#%EF%B8%8F-updating-to-revenge-next>

## 3. Установка ZIP плагина

1. Скачайте или получите файл:

   ```text
   com.gleb.autotranslate.zip
   ```

2. Не распаковывайте и не переименовывайте ZIP.
3. В Discord откройте:

   ```text
   Настройки → Revenge → Plugins
   ```

4. Нажмите значок шестерёнки, чтобы открыть экран **Advanced**.
5. Прокрутите вниз до раздела **Advanced**.
6. Нажмите **Install from file**.
7. В системном файловом менеджере Android выберите `com.gleb.autotranslate.zip`.
8. Проверьте имя и версию плагина в окне подтверждения и согласитесь на установку.
9. Вернитесь в список **Plugins**, найдите **Auto Translate RU** и включите его.
10. Полностью перезапустите Discord, если Revenge покажет такой запрос.

## 4. Проверка

1. Откройте канал с английским сообщением.
2. Под сообщением должен появиться русский перевод с отметкой `🇷🇺`.
3. Напишите тестовое сообщение по-русски.
4. Перед отправкой оно должно быть переведено на английский.

Для работы перевода требуется интернет-доступ к Google Translate. Если перевод не появился, проверьте соединение, состояние плагина и перезапустите Discord.

## 5. Обновление из нового ZIP

Плагин, установленный из файла, считается **Sideloaded** и не получает автоматические обновления из репозитория.

1. Получите новый `com.gleb.autotranslate.zip`.
2. Откройте **Revenge → Plugins → шестерёнка → Install from file**.
3. Выберите новый ZIP и подтвердите обновление.
4. Перезапустите Discord.

Версия нового ZIP должна быть выше установленной. Текущую версию можно посмотреть в карточке плагина.

## 6. Удаление

1. Откройте **Настройки → Revenge → Plugins**.
2. Выберите **Auto Translate RU**.
3. Отключите или удалите плагин.
4. Перезапустите Discord.

## Частые проблемы

### Нет пункта Plugins

Запущен Revenge Classic или Next не загрузился. Повторите раздел перехода на Next и проверьте доступность `revenge.bundle` с телефона.

### Install from file сообщает Invalid ZIP

- не распаковывайте архив;
- используйте исходный `com.gleb.autotranslate.zip`;
- не создавайте новый ZIP вокруг папки с распакованными файлами.

Корректный архив содержит прямо в корне:

```text
manifest.json
index.js
```

### После перезапуска снова загружается Classic

Проверьте, что **Load from custom URL** включён и адрес указан без ошибок:

```text
https://repo.gpodvorotov.ru/revenge.bundle
```

Откройте этот адрес в браузере телефона. Если файл не скачивается, сервер временно недоступен.
