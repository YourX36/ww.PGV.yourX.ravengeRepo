# Установка Auto Translate RU с нуля

Инструкция предназначена для обычного Android-смартфона без root. Компьютер и локальный сервер пользователю не нужны: Revenge Next и плагин загружаются с `repo.gpodvorotov.ru`.

## Что будет установлено

1. **Revenge Manager** — установщик модифицированного Discord.
2. **Revenge Classic** — первоначальная версия, которую устанавливает Manager.
3. **Revenge Next** — версия с поддержкой внешних плагинов.
4. **Auto Translate RU** — перевод входящих сообщений на русский и исходящих русских сообщений на английский.

## Перед установкой

- Убедитесь, что помните данные для входа в Discord и имеете доступ к двухфакторной аутентификации.
- Android может потребовать удалить официальный Discord из-за несовпадения подписей APK. Локальные данные приложения при удалении будут потеряны.
- Revenge является сторонней модификацией и не связана с Discord Inc. Использование модифицированного клиента может нарушать правила Discord. Установка выполняется на ваш риск.
- Скачивайте Manager только из официального репозитория Revenge.

## 1. Установка Revenge Manager

1. На телефоне откройте официальную страницу последнего выпуска:

   <https://github.com/revenge-mod/revenge-manager/releases/latest>

2. Откройте раздел **Assets** и скачайте APK. Актуальный стабильный выпуск на момент написания инструкции — `v1.3.0`:

   <https://github.com/revenge-mod/revenge-manager/releases/download/v1.3.0/revenge-manager-1.3.0.apk>

3. Когда браузер закончит загрузку, откройте APK.
4. Если Android заблокирует установку, нажмите **Settings / Настройки** и разрешите этому браузеру или файловому менеджеру **Install unknown apps / Установка неизвестных приложений**.
5. Вернитесь назад и подтвердите установку.
6. Откройте **Revenge Manager**.

Не скачивайте APK с посторонних сайтов и каталогов приложений.

## 2. Установка Discord с Revenge

1. В Revenge Manager выберите установку Discord/Revenge.
2. Предоставьте Manager запрошенные Android-разрешения на загрузку и установку APK.
3. Выберите рекомендуемую или стабильную версию Discord, если Manager предлагает выбор.
4. Запустите установку и дождитесь завершения скачивания и подготовки APK.
5. Подтвердите системный запрос Android на установку Discord.

Если Android сообщает, что приложение не установлено из-за конфликта пакета или подписи:

1. Проверьте, что данные для входа и 2FA доступны.
2. Удалите официальный Discord.
3. Вернитесь в Revenge Manager и повторите установку.

После установки:

1. Откройте Discord, установленный Manager.
2. Войдите в аккаунт.
3. Откройте настройки пользователя и найдите раздел **Revenge**.

На этом этапе обычно запущен Revenge Classic — это ожидаемо.

## 3. Переход с Revenge Classic на Revenge Next

Официальный Manager пока устанавливает Classic. Для поддержки внешнего Auto Translate нужен Next. Ваш сервер уже размещает production bundle Next по постоянному HTTPS-адресу.

1. В Discord откройте:

   ```text
   Settings / Настройки → Revenge
   ```

2. Включите **Developer Settings**.
3. Вернитесь на один экран назад.
4. В разделе Revenge откройте появившийся пункт **Developer**.
5. Найдите **Load from custom URL** и включите переключатель.
6. В поле URL вставьте без пробелов:

   ```text
   https://repo.gpodvorotov.ru/revenge.bundle
   ```

7. Полностью закройте Discord через список последних приложений.
8. Запустите Discord снова.

Не отключайте **Load from custom URL**: этот адрес используется для загрузки и последующих обновлений Next.

Официальное описание перехода на Next:

<https://github.com/revenge-mod/revenge-bundle-next#%EF%B8%8F-updating-to-revenge-next>

## 4. Проверка Revenge Next

После перезапуска откройте настройки Discord. В разделе Revenge должен появиться пункт:

```text
Plugins
```

Если пункта **Plugins** нет:

1. Убедитесь, что URL введён полностью и начинается с `https://`.
2. Откройте в браузере телефона:

   <https://repo.gpodvorotov.ru/revenge.bundle>

3. Файл должен начать скачиваться без предупреждения о сертификате.
4. Проверьте, что **Load from custom URL** включён.
5. Принудительно остановите Discord через настройки Android и запустите снова.

## 5. Подключение репозитория плагинов

1. В Discord откройте:

   ```text
   Settings → Revenge → Plugins
   ```

2. Нажмите значок шестерёнки — откроется экран **Revenge Plugins Advanced**.
3. Найдите поле **Repository URL**.
4. Вставьте:

   ```text
   https://repo.gpodvorotov.ru/index.json
   ```

5. Нажмите **Add repository**.
6. Убедитесь, что в списке появился репозиторий:

   ```text
   ww.PGV.yourX.ravengeRepo
   ```

7. Если рядом с репозиторием есть переключатель, включите его.

Проверить URL отдельно можно в браузере телефона:

<https://repo.gpodvorotov.ru/index.json>

Должен открыться или скачаться JSON-файл.

## 6. Установка Auto Translate RU

1. Вернитесь в:

   ```text
   Settings → Revenge → Plugins
   ```

2. Нажмите **Browse plugins** или кнопку со значком `+`.
3. Найдите **Auto Translate RU**.
4. Откройте карточку плагина.
5. Нажмите **Install** и подтвердите установку.
6. Вернитесь в список установленных плагинов.
7. Включите **Auto Translate RU**, если он не включился автоматически.
8. Полностью закройте и снова откройте Discord.

Основной способ установки — через репозиторий. Он позволяет Revenge проверять версии и получать обновления.

## 7. Проверка перевода

### Входящие сообщения

Откройте канал с английским сообщением. Через короткое время оно должно выглядеть примерно так:

```text
John
We need to restart the server after the update.

> 🇷🇺 Нужно перезапустить сервер после обновления.
```

Перевод добавляется только локально в вашем Discord. Исходное сообщение другого пользователя не изменяется.

### Исходящие сообщения

Напишите тестовое сообщение по-русски:

```text
Нужно перезапустить сервер после обновления.
```

После нажатия отправки в канал должна уйти английская версия сообщения. Перед первым тестом используйте канал, где допустимы тестовые сообщения.

Для переводов требуется доступ к Google Translate. Если сервис недоступен, исходящий текст отправляется без перевода, чтобы сообщение не потерялось.

## 8. Обновление плагина

Откройте:

```text
Settings → Revenge → Plugins → шестерёнка
```

Далее используйте один из вариантов:

- включите **Update plugins automatically**;
- нажмите **Check for updates** и подтвердите найденное обновление.

После обновления полностью перезапустите Discord, если Revenge попросит это сделать.

## 9. Обновление Revenge Next

Адрес bundle остаётся постоянным:

```text
https://repo.gpodvorotov.ru/revenge.bundle
```

Владелец сервера обновляет файл централизованно. Обычно достаточно полностью перезапустить Discord. Если Next не подхватывает новую сборку, повторно сохраните тот же URL в **Developer → Load from custom URL** и перезапустите приложение.

## 10. Установка плагина из ZIP — запасной способ

Если репозиторий временно не добавляется, скачайте:

<https://repo.gpodvorotov.ru/com.gleb.autotranslate.zip>

Затем:

1. Не распаковывайте ZIP.
2. Откройте **Revenge → Plugins → шестерёнка**.
3. Нажмите **Install from file**.
4. Выберите `com.gleb.autotranslate.zip` в системном файловом менеджере.
5. Подтвердите установку, включите плагин и перезапустите Discord.

Sideloaded-версия может не получать автоматические обновления из репозитория. Поэтому после восстановления доступа лучше установить плагин обычным способом.

## 11. Частые проблемы

### Нет раздела Revenge

Discord установлен не через Revenge Manager либо модификация не загрузилась. Повторите установку через Manager.

### Есть Revenge, но нет Plugins

Работает Classic. Повторите переход на Next и проверьте `revenge.bundle` в браузере.

### Репозиторий не добавляется

- проверьте точность `https://repo.gpodvorotov.ru/index.json`;
- временно отключите VPN, Private DNS или блокировщик рекламы;
- проверьте URL в браузере;
- перезапустите Discord.

### Плагин установлен, но переводов нет

- убедитесь, что плагин включён;
- полностью перезапустите Discord;
- проверьте интернет-соединение;
- попробуйте другое английское сообщение длиной больше одного символа;
- убедитесь, что Google Translate доступен из вашей сети.

### Discord перестал запускаться после перехода на Next

Откройте системные настройки Android, принудительно остановите Discord и очистите только кэш приложения. Не очищайте данные без необходимости. Если это не помогает, переустановите Discord через Revenge Manager и повторите настройку URL.

## 12. Удаление

Удаление плагина:

```text
Settings → Revenge → Plugins → Auto Translate RU → Disable/Uninstall
```

После удаления перезапустите Discord.

Для полного возврата к официальному Discord удалите модифицированное приложение и установите Discord заново из Google Play. Revenge Next официально предупреждает, что простого встроенного отката на Classic нет.
